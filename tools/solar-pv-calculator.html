Frequently Asked Questions

How accurate is this calculator?

This calculator provides preliminary engineering estimates suitable for feasibility studies and early-stage design. Final system design should always be verified using detailed engineering calculations, manufacturer specifications, and applicable electrical standards.

What is Peak Sun Hour (PSH)?

Peak Sun Hour is the equivalent number of hours per day when solar irradiance averages 1000 W/m². It varies depending on geographical location and season.

Can this calculator be used for commercial systems?

Yes. The calculator can be used for residential, commercial, and industrial preliminary PV sizing. Larger projects should be validated using professional PV design software.

Does this replace a detailed engineering design?

No. It is intended for preliminary sizing only. Detailed engineering should include shading analysis, string design, cable sizing, protection coordination, voltage drop calculations, and compliance with local electrical codes.
